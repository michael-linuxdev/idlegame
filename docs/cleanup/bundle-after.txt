## Ziel „Start-Bündel < 450 kB (≈ 140 kB gzip)“

- Das Einstiegs-Bündel selbst liegt jetzt bei 465 kB (135 kB gzip): das gzip-Ziel ist erreicht, roh knapp darüber.
- Ehrlich gemessen (inklusive der sofort mitgeladenen Bündel) sinkt der Start von 777 kB auf 685 kB (−12 %, gzip 233 → 213 kB).
  Rolldown legt Module, die Start und nachgeladene Fenster gemeinsam nutzen, in eigene Bündel (i18n 82 kB, state 53 kB …);
  sie werden trotzdem beim Start gebraucht.
- Was beim Start bleibt und sich nicht nachladen lässt: react-dom (207 kB), alle Texte (86 kB, `t` wird beim Import
  aufgebaut — die englische Runde fasst das ohnehin an), die Spiellogik (146 kB) und die Gartenkarte mit ihren Grafiken.
  Weniger als ~600 kB wären nur mit größeren Umbauten möglich (z. B. Texte je Sprache nachladen, Karten-Ebenen wie
  Fest-Deko/Bewohner verzögert zeichnen). Das ändert sichtbares Verhalten beim Start und wurde deshalb nicht gemacht.
- Nachgeladen (eigene Bündel, im Leerlauf nach dem Start vorgeladen, offline im Precache): Saison- und Markt-Panel,
  Verein, Kapitel-Karten, Notizbuch, Saisonende-Feier, Projekte, Album, Sammlung, Rechtliches, Spielstand, Fest,
  Kreuzen, Deko, Fortschritt sowie html-to-image (nur Foto-Modus).
- Schriften: nur noch woff2 im CSS und im Build (vorher zusätzlich 9 woff-Dateien, ~260 kB), font-display: swap unverändert.
